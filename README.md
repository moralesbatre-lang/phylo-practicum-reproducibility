Reproducible Phylogenomics Workflow for Wheat Relatives
Course Project Overview

This repository documents a reproducible phylogenomics workflow developed during the phylogenomics reproducibility course based on the paper by Glemin et al. The main objective of this project was to reproduce and understand several phylogenomic analyses used to study the evolutionary history of wheat relatives.

The workflow includes:

Gene tree estimation using RAxML-NG
Species tree estimation using concatenation approaches
Species tree estimation using coalescent methods (ASTRAL)
Supertree reconstruction using SuperTriplets
Tree visualization and comparison in R
Exploration of hybridization and introgression analyses

This repository is not intended to perfectly reproduce all analyses from the original publication. Instead, the goal is to document the computational workflow, software setup, commands, intermediate outputs, and challenges encountered during the analyses in a reproducible and transparent manner.

Gene Tree Estimation Using RAxML-NG

Gene trees were estimated from multiple sequence alignments using RAxML-NG with the GTR+G4 substitution model.

Example command for a single alignment:

raxml-ng --msa alignment.aln --model GTR+G4

To automate the analysis for multiple genes, the provided bash script was used:

./04-raxml.sh

This script iterates through alignment files and runs RAxML-NG for each gene.

Generated outputs included:

.raxml.bestTree
.raxml.log
.raxml.bestModel

The resulting gene trees were combined into a single file:

results/04-all_gene_trees.tre
Notes

Gene tree estimation generated thousands of tree files and required substantial computational time. Some analyses were interrupted or restarted due to hardware limitations.

Species Tree via Full Concatenation

The authors provided a fully concatenated fasta alignment:

triticeae_allindividuals_OneCopyGenes.fasta

The full concatenation analysis was run using:

raxml-ng \
  --msa triticeae_allindividuals_OneCopyGenes.fasta \
  --model GTR+G4 \
  --all \
  --bs-trees autoMRE \
  --prefix FullConcat

The course instructions indicated that this analysis could take approximately 24 hours or longer depending on hardware.

Computational limitations

This analysis was computationally intensive on a local laptop environment using WSL. The analysis was initiated successfully and checkpoint files were generated, but the complete analysis required extended runtime.

Outputs generated by RAxML-NG included:

.raxml.log
.raxml.bestTree
.raxml.rba
.raxml.ckp
Species Tree via 10Mb Sliding Windows

The project also explored phylogenetic discordance using concatenated 10Mb genomic windows.

The provided directory:

Concatenation10Mb_OneCopyGenes/

contained approximately 248 fasta alignments.

RAxML analyses for these windows were run using:

./06-raxml-concatenation.sh

This workflow estimated one phylogenetic tree per genomic window.

Notes

This analysis was extremely computationally demanding and generated large numbers of output files.

Species Tree via Coalescent Methods (ASTRAL4)

ASTRAL4 was used to estimate species trees under the multispecies coalescent model.

Individual-level species tree
astral4 -i 04-all_gene_trees.tre -o 07-individual-species-tree-astral4.tre

Visualization in R:

library(ape)


astral_tree <- read.tree("07-individual-species-tree-astral4.tre")
plot(astral_tree)
Species-level tree

A mapping file connecting individuals to species names was generated in R.

Example:

cleaned_individuals <- sub("_[^_]+$", "", all_individuals)


mapping <- paste(all_individuals, cleaned_individuals)
writeLines(mapping, "../results/07-species_mapping.txt")

Then the species-level tree was estimated:

astral4 -i 04-all_gene_trees.tre -a 07-species_mapping.txt -o 07-species-tree-astral4.tre

Challenges and Reproducibility Notes

Several computational challenges were encountered throughout the project:

Long runtimes for RAxML analyses
Memory limitations in local hardware
Interrupted analyses due to system shutdowns
Difficulties connecting RStudio with WSL directories
Problems reproducing some published analyses exactly

Nevertheless, the project successfully documented the overall phylogenomics workflow and generated multiple intermediate and final outputs.

The experience provided practical training in:

phylogenetic workflows,
computational reproducibility,
tree visualization,
software installation,
and handling large-scale phylogenomic datasets.

Conclusions

This project explored several modern phylogenomics approaches for reconstructing species relationships among wheat relatives.

Although not all analyses from the original publication were fully reproduced locally, the workflow successfully demonstrated:

gene tree estimation,
species tree estimation,
supertree reconstruction,
coalescent approaches,
and phylogenetic visualization methods.

The project also highlighted the importance of reproducibility, computational documentation, and workflow organization in modern evolutionary genomics.
